# [Thực hành] Xây dựng Trang Chủ với Bootstrap

## Mục tiêu
Luyện tập ứng dụng các kiến thức Bootstrap 5 và Font Awesome để xây dựng trang chủ hoàn chỉnh:
- **Navbar với Font Awesome**: Thanh điều hướng có biểu tượng icon `fa-home` tinh tế.
- **Hero Section với Carousel**: Trình chiếu slide ảnh tự động (`data-bs-ride="carousel"`) có nút điều hướng trước/sau và indicators.
- **Flexbox Section**: Sử dụng các tiện ích Flexbox của Bootstrap (`d-flex justify-content-center align-items-center`) để căn giữa nội dung.
- **Contact Form**: Biểu mẫu liên hệ chuyên nghiệp với Bootstrap Form Controls (`.form-label`, `.form-control`, `.btn-primary`).
- **Footer**: Chân trang bản quyền ghim cuối trang với Flexbox utilities (`d-flex flex-column min-vh-100`, `mt-auto`).
