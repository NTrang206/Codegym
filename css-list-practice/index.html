[Thực hành] Định Kiểu Danh Sách trong CSS

Khám phá các thuộc tính list-style-type, list-style-image, list-style-position và cách phối hợp màu sắc

2. Kiểu đánh dấu vuông (square)

Sử dụng list-style-type: square; cho danh sách môn học:

  • HTML
  • CSS
  • JavaScript
  • Git

3. Số La Mã viết hoa (upper-roman)

Sử dụng list-style-type: upper-roman; cho các bước học:

  1. Học HTML
  2. Học CSS
  3. Học JavaScript
  4. Học Git

4. Hình ảnh làm dấu (list-style-image)

Sử dụng list-style-image: url('images/check-icon.png'); cho danh sách công cụ:

  • Visual Studio Code
  • Google Chrome
  • GitHub
  • Git

5. So sánh vị trí (outside vs inside)

Dấu ở ngoài lề (Mặc định): list-style-position: outside;

  • Mục thứ nhất nằm ngoài lề biên giới hạn
  • Mục thứ hai minh họa vị trí outside

Dấu ở trong lề nội dung: list-style-position: inside;

  • Mục thứ nhất nằm trọn vẹn bên trong lề biên
  • Mục thứ hai minh họa vị trí inside

6. Thuộc tính rút gọn (list-style)

Thiết lập đồng thời Type và Position: list-style: square inside;

  • Mục rút gọn 1 (Hình vuông + Vị trí inside)
  • Mục rút gọn 2 (Cú pháp ngắn gọn, dễ bảo trì)
  • Mục rút gọn 3 (Chuẩn W3C CSS)

7. Danh sách với màu sắc & khoảng cách

Kết hợp background-color, color, padding và margin:

  • HTML (HyperText Markup Language)
  • CSS (Cascading Style Sheets)
  • JavaScript (Ngôn ngữ lập trình Web)
  • Python (Ngôn ngữ lập trình đa năng)

8. Bài tập tổng hợp: Lộ trình học lập trình Web

Áp dụng kết hợp list-style, màu nền thanh lịch, màu chữ, padding và margin:

  • Chặng 1: HTML - Xây dựng cấu trúc và nền tảng trang web
  • Chặng 2: CSS - Thiết kế giao diện, màu sắc, bố cục Flexbox & Grid
  • Chặng 3: JavaScript - Lập trình tư duy logic và tính năng tương tác
  • Chặng 4: Git - Quản lý phiên bản mã nguồn chuyên nghiệp
  • Chặng 5: GitHub - Lưu trữ dự án trên đám mây và làm việc nhóm
