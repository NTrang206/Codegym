# [Thực hành] Tạo Bố Cục 3 Cột bằng Bootstrap Grid và Flexbox

## Mục tiêu
Luyện tập sử dụng Bootstrap 5 để tạo bố cục linh hoạt và phối hợp đa dạng tính năng:
- **Grid 3 Cột & Flexbox**: Kết hợp `.col-md-4` với Flexbox utilities (`d-flex justify-content-center align-items-center`) để căn giữa nội dung.
- **Margin & Padding Utilities**: Ứng dụng `my-5` và `py-3` để tạo khoảng cách đều đặn, chuẩn xác giữa các section.
- **Display Properties**: Ứng dụng `d-none d-md-block` và `d-block d-md-none` để hiển thị/ẩn nội dung linh hoạt theo breakpoint responsive (>= 768px).
- **Carousel Slideshow**: Trình diễn 3 hình ảnh chuyển động tự động, có điều hướng trước/sau và indicators.
- **Font Awesome Icons**: Tích hợp các icon trực quan (`fa-home`, `fa-paper-plane`, `fa-cube`, v.v.).
- **Bootstrap Form Controls**: Xây dựng form liên hệ đầy đủ các trường (Họ tên, Email, Nội dung).
