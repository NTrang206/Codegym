[Thực hành] Tạo Thanh Điều Hướng Responsive

Thanh điều hướng linh hoạt sử dụng kết hợp HTML, CSS (Flexbox, Media Queries) và JavaScript.

Cách kiểm tra:

  • Trên màn hình Desktop (> 768px): Menu hiển thị dạng thanh ngang đầy đủ, biểu tượng ☰ được ẩn đi.
  • Trên màn hình Mobile (≤ 768px): Menu được ẩn đi và xuất hiện biểu tượng ☰. Khi nhấp vào ☰, menu sẽ trượt mở ra hoặc đóng lại bằng JavaScript class active.
